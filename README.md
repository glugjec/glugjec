# 👋 GLUG JEC

### The GNU/Linux Users' Group of Jorhat Engineering College

[![Website](https://img.shields.io/badge/🌐_Website-glugjec.com-2ea44f?style=for-the-badge)](https://www.glugjec.com)
[![Followers](https://img.shields.io/github/followers/glugjec?label=Followers&style=for-the-badge&color=blue)](https://github.com/glugjec?tab=followers)

We're a student community exploring open source, Linux, security, and building things in public — right out of Jorhat, Assam.

</div>

### 🚀 What we do

- 🐧 Promote FOSS & GNU/Linux on campus
- 🛡️ Run CTFs and security workshops
- 💻 Build tools and community projects, together
- 🌱 Help students make their first open-source contributions
